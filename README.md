# Keyboard Octopus

A connect-the-dots game for the computer lab. The keyboard is the controller:
each dot asks for a character, a key combination or a shortcut, and every
correct answer draws one more line of the octopus. 107 dots, in order.

**Play:** https://hanhoco.github.io/keyboard-octopus/

## For teachers

- Nothing to install and nothing to log in to. Open the link and start.
- Progress is not saved. Closing the tab starts the octopus again.
- The **Keys** menu at the top switches between Ctrl (Windows / Linux) and
  Cmd (macOS). It is detected automatically, but a student can change it.
- The panel on the right shows what the browser receives on every keypress.
  Holding Shift lights its chip while no character appears: that is the
  lesson, not a bug.
- Characters are matched on what the keyboard actually produced, so the game
  works on any layout. The written hints assume US QWERTY.
