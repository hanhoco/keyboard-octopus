Pulpo del Teclado

Las 33 combinaciones del juego, para el teclado Latinoamericano en Windows.

El orden de los puntos se sortea en cada carga Por eso esta hoja lista las combinaciones, no el punto 1, el 2, el 3… Lo que ves acá vale siempre; qué punto pide qué cosa cambia cada vez que se abre el juego. Abajo a la derecha, el juego dice sorteo …: ese número identifica la partida.

Ajustes de esta clase

Afuera: ^   Agregados: / -   Fijados: 106 = SNIP 107 = SCREENSHOT

Con el ^ afuera no queda ninguna tecla muerta. Siguen siendo 107 puntos en el mismo lugar: el dibujo nunca cambia, cambien las preguntas que cambien.

Las 33 combinaciones

Todo el juego se arma con estas. Enseñá estas 33 y el pulpo entero queda cubierto, salga el sorteo que salga. A la derecha, dónde queda la tecla cuando el nombre no alcanza.

Los dos últimos puntos son siempre los mismos

106 SNIP → Win + Shift + S captura un pedazo.   107 SCREENSHOT → PrtScn captura todo.

Están fijados, así que el sorteo no los mueve. Ojo: Windows suele quedarse con estas dos antes de que el navegador las vea; si una máquina no las acepta, que el chico apriete Skip y siga.

¿Querés la lista punto por punto?

Se puede, fijando el sorteo. En game-config.json agregá una línea con el número que quieras:

"shuffle": true,
"seed": 20260825,

Con eso todas las máquinas muestran las mismas preguntas en el mismo orden toda la clase, y se puede imprimir una lista punto por punto que coincida. Sin esa línea, cada carga sortea de nuevo — mejor para practicar, imposible de listar.
